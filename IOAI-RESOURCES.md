# IOAI 2026 Learning Resources

> **Editable catalogue.** Add or improve resources here. The website data should be generated from this file, not manually maintained in a second copy.

## How to use this file

For each topic, aim for **2–3 useful resources** rather than a long list:

1. **Start here:** a clear, focused explanation.
2. **Practice/build:** a short exercise, interactive demo, or runnable notebook.
3. **Go deeper:** an advanced reference only when it adds real value.

Each entry includes its purpose and an estimated time for the relevant section, not the entire course. Prefer a specific lesson over a broad homepage. Avoid resources that are too long, too advanced for the topic, outdated, or only loosely related.

**Review rule:** Entries are marked *Needs verification* until a maintainer opens the link and confirms the page directly teaches the topic and its estimated length is realistic. Do not mark a link verified based on its title alone.

## Quality checklist

- Directly teaches the topic, not merely the general subject.
- Appropriate for the listed level.
- Clear explanation plus an example or exercise where possible.
- Reasonable time commitment; break large courses into a specific lesson.
- Stable URL and no unnecessary payment/account barrier.
- Prefer official docs, respected course material, strong visual explainers, and runnable code.
