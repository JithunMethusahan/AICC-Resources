# IOAI Transition

**Level:** 🏆 Competition
**Prerequisites:** Strong Python, data handling, ML and enough deep learning to choose appropriate methods

This stage is the bridge from **knowing AI** to **solving unfamiliar AI problems**.

## Learn this problem-solving loop

1. Read the task carefully.
2. Identify the data, target, metric and constraints.
3. Inspect the data before choosing a model.
4. Build the simplest useful baseline.
5. Create a reliable local validation method.
6. Experiment one meaningful change at a time.
7. Analyze errors and improve the pipeline.
8. Track compute, time and memory constraints.
