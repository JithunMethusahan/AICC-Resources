# IOAI Learning Roadmap

A simple path from your first Python program to solving IOAI-style AI problems.

You do **not** need to learn all of AI before you start practicing. Learn a topic, build something small, then move forward.

## The path

1. 🟢 [Python](./python) — learn to program
2. 🟢 [Data & Tools](./data) — work with datasets
3. 🟢 [Mathematics](./math) — learn the math you actually need
4. 🟡 [Machine Learning](./machine-learning) — build your first models
5. 🟡 [Deep Learning](./deep-learning) — neural networks and PyTorch
6. 🟡 [AI Domains](./domains) — computer vision, NLP and audio
7. 🔴 [Advanced AI](./advanced) — deeper methods and modern AI
8. 🏆 [IOAI Preparation](./ioai-preparation) — learn to solve unfamiliar tasks

## Already know some of this?

Skip ahead. The roadmap is a recommended order, not a rule.

## How to use each stage

For every topic, aim to:

**Understand → Code → Experiment → Check yourself → Move on**

Each page keeps the core resources small. Community-submitted resources can be explored separately so the roadmap does not become a link dump.

## Practice

This site focuses on **learning**. For full competition practice, use the AICC practice environment rather than duplicating it here.
