# Deep Learning

**Level:** 🟡 Intermediate
**Prerequisites:** Python, data handling, ML basics and useful linear algebra intuition

## Learn in this order

1. Tensors and datasets
2. Neural network layers
3. Forward pass and loss
4. Backpropagation and gradients
5. Optimizers and learning rates
6. Regularization
7. CNNs
8. Attention and transformers
9. PyTorch training workflows

## ⭐ Main course

**fast.ai — Practical Deep Learning for Coders**  
https://course.fast.ai/

A practical route into deep learning. Code along and understand what each part is doing.

## ⭐ Framework

**PyTorch Tutorials**
