# Data & Scientific Python

**Level:** 🟢 Foundation
**Prerequisite:** Basic Python

## Learn in this order

1. NumPy arrays and vectorized operations
2. Pandas tables and data cleaning
3. Matplotlib and data visualization
4. Jupyter notebooks
5. Dataset inspection and exploratory analysis
