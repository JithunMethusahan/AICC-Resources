# Machine Learning

**Level:** 🟡 Intermediate
**Prerequisites:** Python + basic data work + core math

## Learn in this order

1. What machine learning is
2. Regression
3. Classification
4. Decision trees and ensembles
5. Clustering
6. Features and preprocessing
7. Train/validation/test splits
8. Metrics and error analysis
9. Overfitting and regularization
10. Cross-validation and model selection

## ⭐ Main course

**Google Machine Learning Crash Course**  
https://developers.google.com/machine-learning/crash-course

Use the modules in order and complete the exercises that match the topics you are learning.
