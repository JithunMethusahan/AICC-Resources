# Python Foundation

**Level:** 🟢 Beginner

Start here if you are new to programming.

## Learn in this order

1. Syntax, variables and types
2. Conditions and loops
3. Functions
4. Lists, dictionaries, sets and strings
5. Files, modules and libraries
6. Debugging and problem solving
7. Basic OOP

## ⭐ Main resource

**CS50P — Introduction to Programming with Python**  
https://cs50.harvard.edu/python/

Follow the lessons and code along. You do not need to finish every optional exercise.

## Practice

**Kaggle Learn — Python**  
https://www.kaggle.com/learn/python

Short interactive exercises to reinforce the basics.

## Reference

**Python Tutorial — Official Docs**  
https://docs.python.org/3/tutorial/

Use this when you need a reference while coding.

## Move on when...

You can write small programs without copying every line, use functions and collections comfortably, and debug simple errors.
