# Natural Language Processing

NLP deals with text and language data. IOAI-style problems can range from simple text processing to modern transformer-based systems.

## Topics

- **Text Preprocessing:** tokenization, normalization, and preparing text for models.
- **Word Embeddings:** representing words and text as vectors.
- **Language Models:** from statistical models to pretrained transformers.
- **Prompting & Inference:** using and evaluating pretrained models when appropriate.

## How to think about NLP tasks

Do not assume that every NLP problem needs a large language model. Start by inspecting the data and task. Depending on the problem, useful approaches can include text statistics, classical ML, embeddings, pretrained encoders, transformers, or generation models.

Learn the fundamentals first, then become comfortable with the Hugging Face ecosystem and with evaluating models properly.
