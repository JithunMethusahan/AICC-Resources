# Computer Vision

Computer vision covers problems involving images and video. The goal is not to memorize one model family, but to understand how to represent visual data and choose an approach that fits the task.

## Subsections

- **Image Classification:** assigning labels to images.
- **Object Detection:** finding and labeling objects.
- **Image Segmentation:** making pixel-level predictions.
- **Vision Transformers:** using attention-based architectures for visual data.

## What to learn

Start with image representations, normalization, augmentation, convolution, and evaluation. Then learn common CNN architectures and pretrained models. After that, explore detection, segmentation, and transformers.

For a competition task, a pretrained model can be a useful baseline, but it is not automatically the best solution. Check the data, compute limits, and validation results first.
